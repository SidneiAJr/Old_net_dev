# php5-escola (~2014)

Sistema de cadastro de alunos em PHP 5 + MySQLi, estilo curso técnico.

- **Tecnologia:** PHP 5.x + MySQLi + MyISAM
- **Período:** ~2014
- **Status:** ☠️ Código histórico
- **Por que era assim:** sem framework, sem ORM, `mysqli_*` na mão, sessão simples, senha em texto puro.
- **O que não existia ainda:** Composer maduro, PDO como padrão, Laravel popular, `.env`, password_hash.
- **Equivalente moderno:** Laravel/Symfony + Eloquent + bcrypt + `.env`.
- **Gambiarras clássicas:** include de `conexao.php` em todo arquivo, guard de sessão copiado.
